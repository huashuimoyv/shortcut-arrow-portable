快捷方式箭头 · 便携版

单独处理一个快捷方式：
把桌面上的快捷方式（.lnk）拖到「快捷方式箭头.exe」文件上，
或拖进已经打开的程序窗口，也可以点击窗口底部的「单个图标」选择文件。
弹出选择窗口后：
1.「应用圆角」：只改变这个快捷方式的图标，保留启动目标、参数和工作目录。
   可选「将浅灰 / 白色背景统一为米白色」；该选项会改变图像中的浅灰和白色，先看预览。
2.「恢复原图标」：恢复本工具第一次处理前的图标。之后其他程序改过图标时拒绝覆盖。
3.「生成无箭头 EXE」：另存一个无箭头启动器，原快捷方式保留。
   启动器使用当前已保存的图标；要同时圆角，请先点「应用圆角」。
   它把快捷方式副本封装在 EXE 内，保留原来的启动参数，不依赖桌面上的原快捷方式。
   原目标程序仍须安装在可用位置。首次启动时将内部快捷方式释放到用户数据目录。
   不替换原快捷方式，也不更改全机箭头设置；不需要时删除生成的 EXE 即可。
   不支持把文件拖到生成的启动器上作为额外启动参数。

Windows 的原生箭头属于快捷方式类型的系统叠加图标，不能用本工具的全局设置
只去掉某一个 .lnk 的箭头。因此这里通过真正的 EXE 启动器实现单个图标无箭头。
请正常双击打开工具；以管理员身份运行的窗口可能无法接收普通桌面的拖放。
单个图标及其备份位于 %LocalAppData%\ShortcutArrowPortable\Icons。
启动器内部快捷方式位于 %LocalAppData%\ShortcutArrowPortable\Launchers。
这些文件在使用期间请保留，移动工具 EXE 不会影响已设置的圆角图标。

全局箭头设置：
双击「快捷方式箭头.exe」，点击「去除箭头」，允许管理员权限请求。
如果没有立即变化，点击「重启桌面」；桌面和任务栏会短暂消失，文件夹窗口可能关闭。
先完成文件复制或移动，再重启桌面。也可以自行注销后重新登录。
需要撤销时，点击「恢复原样」，还原本工具首次修改前的设置。

只需携带这个 EXE，无需安装或联网；使用 Windows 自带的 .NET Framework 4.x。
适用于 Windows 10/11 桌面环境。当前在 Windows 10 上完成编译和隔离读写测试；
真实桌面去箭头效果需要运行后确认，尚未验证 Windows 11 的实际效果。

设置作用于整台电脑的快捷方式箭头。程序不会修改快捷方式目标或删除 IsShortcut。
仅修改 HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons 中的 29 值。
首次操作前保存原值及其类型；检测到其他工具后续更改时拒绝覆盖。

为保证 EXE 移动、删除后不会出现丢失图标，透明图标和原设置备份存放在：
%ProgramData%\ShortcutArrowPortable
因此这是免安装便携版，但不是零落地文件。去箭头期间请保留该目录。
恢复后备份会移除，透明图标暂留供桌面旧缓存读取；注销后可删除该目录。
程序不常驻、不添加开机启动、不自动重启电脑、不自动注销。

源码及重建脚本位于「源码」文件夹，使用系统自带 C# 编译器。
